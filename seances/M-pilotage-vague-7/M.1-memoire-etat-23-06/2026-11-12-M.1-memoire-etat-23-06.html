RÉCUPÉRER

Au 23/06, la chaîne MRD → BRD → PRD → SRD → Code de Yanis était construite de bout en bout, mais seul le BRD était verrouillé : ses dettes s'étaient empilées à partir du NFR du PRD, à l'endroit où la théorie de la chaîne touche le réel.

1 · Déclencheur

Le 20/06, la séance d'amendement prévue après les 11 séances du SRD est remplacée. Yanis lit deux notes du vault et en tire ce constat : le pipeline ne peut pas valider sa propre valeur, seul un chiffre extérieur le peut. Il instrumente donc le ledger (AS), puis l'analyse (AT) : une séance SRD coûte 2,2 fois une séance BRD [12] [13]. Il ouvre ensuite le dernier maillon, le Code, pour finir la chaîne avant un voyage le 01/07 [2] [22].

2 · Objectif

Fermer le terminus de la chaîne. Le gabarit Code devait porter les cérémonies Scrum (Sprint Planning, Gate DoD, Sprint Review, Retrospective) et renvoyer vers le haut ce que le réel révèle : « Bugs et révélateurs d'implicites → corrections SRD → précisions PRD → révisions BRD » [16]. Bénéfice attendu : une chaîne complète, où chaque document est stable en lui-même, ne déborde pas sur ses voisins et descend d'un parent réel [4].

B touchait une règle de toute la chaîne (« le noyau reste ici, l'image descend »), C touchait deux documents déjà verrouillés ; A n'a pas de raison écrite trouvée. D a été choisie par la règle D5 [7] [8] [9]. Lecture de Claude (moyenne) : le verrou précoce du BRD (05/06) a rendu chaque déplacement coûteux.
  • Le NFR est un carrefour. Il descend vers le SRD (« Deployment Constraints ⮌ PRD#NFR »), qui hérite donc de son trou, et il est vérifié par le Code (« Métriques runtime ↗ vérifie PRD#NFR ») [10] [16].
  • La frontière avec le réel se voit dans les gabarits. La seule arête ↗ de la chaîne est dans le Code (0, 0, 0, 0, 1). L'instance SRD est « un document vivant qui croît d'une User Story par sprint ». Il n'existe pas de spec/Code.md : les ancres Implementation et Tests sont « reportées à l'instance inexistante » [18] [20] [14]. Personne n'a vérifié qu'aucune autre section ne tient sa vérité du bas : le contrôle d'AV porte sur ce qui est écrit, et le 08/06 Yanis notait déjà que 4 autres arêtes du PRD n'étaient « pas vérifiées contre le contenu » [8] [25].
  • Le retour Code → SRD → PRD → BRD est décrit, pas câblé. Il est écrit en texte dans le gabarit Code ; seule l'arête vers le NFR est formalisée [16].
  • Le travail de juin n'a jamais été fusionné. master s'arrête au 31/05 ; 138 commits vivent seulement sur sprint-15 [3].
  • Le ledger a des trous. Les 4 lignes des forges n'ont jamais été ajoutées ; AW est étiquetée « prd » et AX « brd », alors qu'elles relèvent du cycle Code. Le cycle Code (AU → AZ) coûte 30,41 $ sur 6 lignes [15] [17].
